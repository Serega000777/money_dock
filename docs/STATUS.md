# STATUS — что реализовано в Amola Finance

Живой документ. Обновляется агентом, когда меняется реализованное, окружение или деплой.
Правила и протокол — в [`AGENTS.md`](../AGENTS.md), история задач — в
[`AGENT_LOG.md`](AGENT_LOG.md). Последнее обновление: 2026-10-09.

## Продукт в двух строках

Финансовый автопилот: операции (вручную, голосом, текстом, по фото чека, импортом выписок,
через Siri/Команды), категоризация, «сколько можно безопасно потратить», аналитика, цели,
обязательные платежи, долги, заметки, общие счета и ИИ-ассистент. Основная платформа —
Telegram Mini App (@amola_finance_bot); тот же клиент собирается под iOS/Android.

## Инфраструктура и прод

- Прод: https://amola-finance.ru, один VPS, `/root/money_dock`, три контейнера
  (Postgres, API, Caddy с автоматическим HTTPS). Подробности — [`deploy.md`](deploy.md).
- Деплой: `git pull` + `docker compose --env-file .env.production -f infrastructure/docker/docker-compose.prod.yml up -d --build`.
- CI: GitHub Actions (`.github/workflows`) — lint, typecheck, тесты на Postgres.
- Репозиторий: `github.com/Serega000777/money_dock`, ветка `main`.

## Реализовано

### Платформа и вход

- Монорепо pnpm + Turborepo; NestJS + Drizzle + PostgreSQL; клиент Expo Router
  (react-native-web) — один код для Telegram Mini App и нативных сборок.
- Вход молча по Telegram `initData`; вне Telegram — онбординг (5 тёмных неоновых экранов),
  экран регистрации (Telegram; Yandex ID/VK ID/телефон — заготовки «скоро»),
  «Продолжить без регистрации» (демо-вход, в проде отключён).
- Светлая/тёмная тема (по умолчанию тёмная), токены дизайна, haptics на клавиатуре
  ввода суммы, загрузочный экран, аватар (загрузка), референсные карты банков и Pro-дизайны
  карт.
- Юридические документы (152-ФЗ) в приложении, поддержка/обратная связь через Telegram.

### Счета и операции

- Счета (наличные/карта/банк), валюта, начальный баланс, выбор банка с дизайном карты (Pro),
  удаление счёта (архив: пропадает из списка и баланса, операции остаются в истории).
  Картинки карт — WebP ~30 КБ (`apps/app/public/bank-cards`), Т-Банк нарисован в SVG; под
  выбором дизайна и в «Условиях использования» — оговорка о товарных знаках банков.
- **Общие счета**: участники, приглашения по ссылке (`/invite`), управление (`/account-sharing`).
- Операции: расход/доход/перевод, создание, редактирование (в т.ч. из разбивки категорий),
  soft-delete с «отменить», идемпотентный `clientId`, дата, заметки.
- Категории: системные (seed) + свои (тип расход/доход, ~55 иконок по сферам: авто/СТО/мойка,
  ремонт, красота, подписки, дети, питомцы и т.д.); категоризация детерминированная: личное правило →
  история → алиас мерчанта → MCC → локальный keyword-классификатор (без LLM).
- Аудит-логи, единый error envelope, экспорт (отчёт из кабинета).

### Ввод

- **Голос**: браузерный SpeechRecognition (Android/десктоп) и запись + Yandex SpeechKit на
  сервере (iPhone/любой браузер без SpeechRecognition); черновик с редактированием на месте,
  выбором даты и категории, подтверждение перед записью. Разрешение на микрофон не
  переспрашивается на каждую запись; один общий поток микрофона на всё приложение. Шторки
  (`BottomSheet`) — непрозрачные, со скроллом внутри, закрываются свайпом вниз за верх и тапом
  вне; в Telegram вызывается `disableVerticalSwipes`. Свайп от левого края — «назад» туда,
  откуда пришёл (`useEdgeSwipeBack`); клавиатура не задирает экран (`useVisualViewportLock`).
- **Текстовые команды** («кофе 350», «зп 80 тысяч», «потратил 840 в кафе») — парсер `commands`.
- **Скан чека**: фото → DeepSeek vision (через Yandex AI Studio) → короткая фраза → тот же
  парсер → черновик на подтверждение.
- **Быстрый ввод / Shortcuts** (`/shortcut`): Apple Команды (iOS) и HTTP Shortcuts (Android),
  ключи доступа (`shortcut-credentials`), режимы text/photo, сохраняет сразу; результат попадает
  в «Проверку быстрого ввода». Siri/виджет — [`siri-and-widget.md`](siri-and-widget.md).
- **Импорт выписок**: CSV и PDF (`rowsFromPdfTables` / `rowsFromStatementText` в
  business-rules: заголовок ищется на любой странице, иначе колонки по содержимому; текстовые
  выписки вроде Озона режутся на записи по строке с датой), дедупликация, предпросмотр, «Проверка быстрого ввода»
  (Review Inbox: подтвердить/править/категоризировать, возможные переводы).
- Контракт `BankProvider` + адаптеры Manual/CSV (банки по API — впереди).

### Аналитика и планирование

- Главная: баланс, «свободные деньги» (safe-to-spend), прогресс месяца, карты и счета,
  быстрые действия, обязательные платежи, цели.
- Аналитика: переключатель расходы/доходы, разбивка по категориям, Insights (советы без LLM).
- «Обязательные расходы» (регулярные платежи), «Цели» (накопления), «Долги»
  («мне должны / я должен»), «Мои заметки».

### ИИ-ассистент (Amola Assistant)

- Экран `/assistant`, текст и голос; плавающая кнопка с иконкой-искрами над «+» в нижнем
  меню, видна на всех вкладках.
- Роутер: детерминированный Voice Engine → LLM-fallback (DeepSeek V4 Flash через Yandex AI
  Studio, затем GigaChat; для GigaChat в образ вшит сертификат Минцифры
  `apps/api/certs/russian-trusted-ca.pem`). LLM только классифицирует/перефразирует.
- Вопросы про итоги («сколько доходов в сентябре», «а в августе», «за прошлый месяц»,
  «за всё время», «доходы и расходы за сентябрь») разбирает `totals-query.ts` и считает
  бэкенд; уточнения «а сколько заработал» / «а доход» берут период из прошлого вопроса.
  Создание/изменение/удаление операций, регулярных платежей, целей — через pending
  actions с подтверждением. См. ADR 0010.

### Тарифы и оплата

- Планы `free` / `pro` / `pro_bank`; администратор и владелец = `pro_bank` без лимитов.
- **Бесплатно в месяц (счётчики `usageCounters`)**: голос 3, импорт выписок 1, ИИ-ассистент 3,
  быстрый ввод (Shortcuts, включая фото чека) 3. Дальше — 403 с текстом про Pro и окно
  оплаты `PaywallModal`. Pro — без ограничений, плюс дизайн банковских карт и совместные
  счета без лимитов участников.
- Кнопка ИИ: Pro — корона и свечение; бесплатно с остатком — бейдж с числом; лимит исчерпан —
  серая с замком, тап открывает оплату.
- Оплата — Telegram Stars (`payments.controller`, `applyStarsPayment`), экран `/upgrade`.

### Telegram-бот и админка

- Бот: приветствие с баннером, запрос номера, юридические ссылки, webhook.
- Админ-панель (`/admin`): сводка по пользователям/планам; ссылка в кабинете видна только
  владельцу (`OWNER_TELEGRAM_ID`).

## Известные ограничения / дальше

- Не сделано: Yandex ID / VK ID, вход по телефону, уведомления (`NotificationsModule`),
  банки по API (только контракт и CSV/ручной), App Store/Google Play публикация
  (подготовка — [`native-release.md`](native-release.md)).
- Цены Stars и тексты paywall живут в `entitlements`/`payments` и `paywall.tsx`.
- Состояния кнопки ИИ «бесплатно с остатком» и «заблокировано» проверены только логикой и
  типами, визуально в браузере смотрели лишь состояние Pro.
- Дизайны карт банков с их логотипами — платная Pro-функция; это коммерческое использование
  чужих товарных знаков (ст. 1484/1515 ГК РФ). Решение за владельцем: разрешение банков,
  бесплатный доступ или нейтральные дизайны. Оговорка в приложении ответственность не снимает.
- `pnpm format:check` в CI падает на ~34 старых файлах (не связано с последними задачами).
- Локальные сессии агентов не синхронизируются между машинами — единственный общий след
  работы это git и `docs/AGENT_LOG.md`.
