# Siri и виджет с микрофоном

Цель: сказать «Добавь 500 рублей на продукты» Siri (или нажать иконку микрофона на
домашнем экране) — операция записывается **без подтверждения**, а внутри приложения её
можно подтвердить, изменить или удалить.

## Что уже готово (сервер)

`POST /commands/capture` — единственная точка входа для любого «слепого» ввода.

```http
POST /commands/capture
Authorization: Bearer <access token>
Content-Type: application/json

{ "text": "потратил 840 рублей в кафе", "source": "voice", "clientId": "<uuid>" }
```

Что делает эндпоинт:

1. разбирает фразу тем же парсером, что и экран «Голос и текст»;
2. сохраняет операцию со статусом `needs_review` и источником `voice`;
3. кладёт её в Review Inbox с причиной `unconfirmed_capture` и уверенностью парсера;
4. `clientId` даёт идемпотентность: повтор того же запроса не создаст дубль.

Поэтому неверно распознанная фраза никогда не портит статистику молча — она ждёт
решения на экране «Нужно проверить».

Ограничение частоты — 30 запросов в минуту, как и у `/commands/parse`; голосовые
операции при этом расходуют месячный лимит тарифа.

## Три способа подключить

### 1. Быстрая команда iOS (работает без нативной сборки)

Приложение «Команды» → новая команда:

1. **Запросить ввод текстом (диктовка)** — фраза от пользователя;
2. **Получить содержимое URL** → `https://<api>/commands/capture`, метод `POST`,
   заголовок `Authorization: Bearer …`, тело JSON из шага 1 + `clientId`;
3. Назвать команду «Добавь расход» — Siri отзывается на это имя;
4. «На экран «Домой»» — команда превращается в иконку, то есть в тот самый виджет с
   микрофоном, который добавляет операцию не открывая приложение.

Чего не хватает для релиза: долгоживущего **токена быстрой команды** (сейчас access
token живёт 15 минут). Нужен отдельный тип токена с правом только на `capture`,
отзываемый из кабинета — это отдельная задача, спроектирована так, чтобы не выдавать в
команду обычный refresh token.

### 2. App Intents / SiriKit (нативная сборка)

`AppIntent` с параметром-фразой, вызывающий тот же эндпоинт, плюс `AppShortcutsProvider`,
чтобы Siri понимала команду без настройки пользователем. Требует dev-build Expo
(`expo prebuild` + swift-таргет), внутри Telegram Mini App недоступно.

### 3. Виджет WidgetKit / Android App Widget (нативная сборка)

Кнопка микрофона на домашнем экране: `AppIntent` внутри виджета (iOS 17+) записывает
операцию прямо из виджета, без открытия приложения. Тот же `POST /commands/capture`.

## Порядок работ

| Шаг | Где | Статус |
| --- | --- | --- |
| Эндпоинт capture + неподтверждённые операции | `apps/api` | сделано |
| Причина `unconfirmed_capture` в Review Inbox | `apps/api`, `apps/app` | сделано |
| Токен быстрой команды (scoped, отзываемый) | `apps/api` | не начато |
| Инструкция и QR внутри кабинета | `apps/app` | не начато |
| App Intents + виджет | нативная сборка | не начато |
