# API

Пока один эндпоинт — остальные документируются здесь по мере появления модулей
(Stage 1+). Формальный OpenAPI/Swagger подключается вместе с первым реальным модулем
(AuthModule), чтобы описывать сразу настоящие DTO, а не заглушки.

## `GET /health`

Проверяет, что процесс жив и что соединение с Postgres работает.

```json
{ "status": "ok", "db": "ok" }
```

`status: "degraded"` / `db: "error"` — приложение работает, но БД недоступна.
