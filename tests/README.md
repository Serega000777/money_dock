# tests/

Unit-тесты лежат рядом с исходным кодом (`*.test.ts` в пакетах, `*.spec.ts` в `apps/api`).
E2e-сценарии одного приложения (например, auth + IDOR через реальный HTTP + Postgres)
тоже лежат рядом с относящимся модулем в `apps/api/src/**/*.e2e.spec.ts` — тот же jest,
без отдельной конфигурации, matched тем же `testRegex`.

Эта папка — для сценариев, которые не колокейтся ни с одним отдельным приложением:
контрактные тесты между API и клиентом, миграционные тесты, сценарии на несколько
сервисов. Появится, когда возникнет первый такой сценарий.
